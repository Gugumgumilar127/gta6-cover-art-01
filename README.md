**Palm Heat Cover Studio** — an offline web app that turns your own photos and a caption into multi-panel GTA-style cover art: a cast of labelled panels, a sunset or neon colour grade, chrome poster lettering with a script subtitle, and the full magazine furniture (review quote, volume chip, tagline, credits, barcode, original-art seal). Fill the panels with one photo or several, drag and zoom each photo into place, edit every word, and export a share-ready PNG in the common post sizes — 1080 x 1080, 1080 x 1350 and 1920 x 1080. Everything runs in the browser from static files; your photos never leave your machine. All artwork, lettering and fonts are original or openly licensed (Anton, SIL OFL; Yellowtail, Apache 2.0) — no Rockstar Games logo, artwork or font files.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```
